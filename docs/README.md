# Documentation Index

The documentation is intentionally split by decision boundary so that Issues and pull requests can link to stable acceptance criteria.

| Area | Source of truth |
|---|---|
| Intent and scope | `decisions/PROJECT_CHARTER.md` |
| Legacy defects | `research/LEGACY_AUDIT.md` |
| Model definition | `research/RESEARCH_SPEC.md` |
| Split, metrics, tuning | `research/EVALUATION_PROTOCOL.md` |
| Literature and attribution | `research/LITERATURE_REVIEW.md` |
| User workflows | `product/PRODUCT_SPEC.md` |
| Runtime and deployment | `architecture/SYSTEM_DESIGN.md` |
| Public interfaces | `contracts/API_AND_ARTIFACT_CONTRACT.md` |
| Work management | `delivery/KANBAN_PLAYBOOK.md` |
| Known risks | `delivery/RISK_REGISTER.md` |

`PROJECT_MEMORY.md` is a session index, not a duplicate specification.
